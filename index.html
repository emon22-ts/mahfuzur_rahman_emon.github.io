EduStream+

A learning platform where educators publish courses that combine video lectures, illustrated notes and audio in one place. Built to stay fast and secure under real load.

  • Direct-to-blob uploads with scoped, time-limited SAS tokens handle 1GB+ videos without request timeouts.
  • Two-tier content moderation (Azure AI Content Safety with a local fallback) screens all user-submitted text.
  • Secrets held in Azure Key Vault via Managed Identity, with Helmet, rate limiting and Application Insights telemetry; shipped through GitHub Actions.

Smart Eye

An explainable ocular-health screening platform that fuses three AI pipelines — fundus and anterior-segment CNN classifiers plus real-time fatigue detection — into one Ocular Health Index.

  • Grad-CAM heatmaps show which image regions drove each prediction.
  • A Mamdani fuzzy inference system in pure NumPy fuses confidence, fatigue and symptom intensity.
  • React + Vite over a FastAPI API, with PDF reports and an EN/BN bilingual UI.
